# บันทึกรายรับรายจ่าย

เว็บภาษาไทย React + TypeScript + Tailwind CSS + Vite เก็บข้อมูลจริงใน IndexedDB โดยเริ่มต้นไม่มีรายการตัวอย่าง

## รันในเครื่อง

ใช้ Node.js 22.12 ขึ้นไป

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (ปกติ http://127.0.0.1:5173) ใช้ origin เดิมเสมอเพื่อเข้าถึงข้อมูลชุดเดิม

```sh
npm test
npm run build
```

นำโฟลเดอร์ dist ไปให้บริการผ่าน static hosting ได้ ต้องเปิดผ่าน HTTP/HTTPS ไม่ใช่ดับเบิลคลิก index.html

## การใช้งาน

- เปิด **บัญชีและกระเป๋า** แล้วเพิ่มบัญชีพร้อมยอดตั้งต้น เลือกใช้กระเป๋าย่อยได้เป็นรายบัญชี ยอดตั้งต้นและเงินที่ยังไม่ได้แบ่งจะอยู่ใน **เงินที่ยังไม่จัดสรร** ของบัญชีที่เปิดใช้กระเป๋า
- ใช้ **โอนเงิน** เพื่อย้ายเงินระหว่างบัญชี หรือเลือกคนละกระเป๋าในบัญชีเดียวกันเพื่อจัดสรรเงิน การโอนแสดงในประวัติของบัญชีที่เกี่ยวข้อง ส่วนงบและกราฟคิดจากรายรับรายจ่ายของเดือนที่เลือก
- เปิดรายละเอียดบัญชีเพื่อดูประวัติทุกเดือน แก้ไข หรือเก็บถาวร บัญชีและกระเป๋าที่มียอดหรือมีประวัติจะเก็บถาวรได้และยังเปิดดูย้อนหลังได้
- รายการจากเวอร์ชันเดิมยังอยู่ในรายงาน เปิด **รายการเดิมที่ยังไม่ผูกบัญชี** เพื่อเลือกบัญชีและดูผลต่อยอดก่อนยืนยัน ถ้าจะผูกรายการย้อนหลัง ให้ใช้ยอดตั้งต้นก่อนรายการแรกที่จะผูก ถ้าใช้ยอดจริงวันนี้ ให้ผูกเฉพาะรายการที่ยังไม่ได้สะท้อนในยอดนั้น
- JSON เก็บบัญชี กระเป๋า ยอดตั้งต้น รายรับรายจ่าย การโอน หมวดหมู่ และงบทุกเดือน รองรับไฟล์เวอร์ชัน 1 และ 2 โหมดเพิ่มรวมเก็บข้อมูลปัจจุบันเมื่อรหัสตรงกัน โหมดแทนที่ต้องยืนยันก่อนบันทึก
- CSV จากตารางรายเดือนใช้ตัวกรองปัจจุบัน หากต้องการรวมการโอนและข้อมูลต้นทางกับปลายทาง ให้ส่งออก CSV จากหน้าสำรองข้อมูล

## ข้อจำกัด

ยอดสะสมคิดจากรายการทั้งหมดที่บันทึก รวมรายการลงวันที่ล่วงหน้า ระบบตรวจยอดคงเหลือหลังการเปลี่ยนแปลง การแก้ไขหรือลบย้อนหลังที่ทำให้แหล่งเงินใดติดลบจะถูกปฏิเสธ

ข้อมูลอยู่ในเบราว์เซอร์ โปรไฟล์ และ origin ที่ใช้ ไม่มีการเชื่อมต่อธนาคารหรือซิงก์ข้ามอุปกรณ์ ควรเก็บ JSON สำรองไว้ในที่ปลอดภัย เมื่อข้อมูลเปลี่ยนจากอีกแท็บ ให้รีเฟรชก่อนบันทึกอีกครั้ง ไฟล์นำเข้าสูงสุด 10 MB และ 100,000 รายการรวมการโอน จำนวนเงินต่อรายการ ยอดตั้งต้น และงบสูงสุด 1 พันล้านบาท

## การทดสอบ

Vitest และ fake-indexeddb ครอบคลุมยอดตั้งต้น การจัดสรร การใช้เงินและโอนข้ามบัญชี การแก้ไขและลบ การตรวจเงินไม่พอ การย้ายข้อมูล IndexedDB เวอร์ชัน 1 การกู้คืน JSON ทั้งสองโหมด การเปิดฐานใหม่ และ CSV
