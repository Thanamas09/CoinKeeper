# พอดี • บันทึกรายรับรายจ่าย

เว็บภาษาไทย React + TypeScript + Tailwind CSS + Vite เก็บข้อมูลจริงใน IndexedDB โดยเริ่มต้นไม่มีรายการตัวอย่าง

## รันในเครื่อง

ใช้ Node.js 22.12 ขึ้นไป

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (ปกติ http://127.0.0.1:5173) ใช้ origin เดิมเสมอเพื่อเข้าถึงข้อมูลชุดเดิม

```sh
npm test
npm run build
```

นำโฟลเดอร์ dist ไปให้บริการผ่าน static hosting ได้ ต้องเปิดผ่าน HTTP/HTTPS ไม่ใช่ดับเบิลคลิก index.html

## การใช้งาน

- เลือกเดือน เพิ่ม/แก้ไข/ลบรายรับรายจ่าย และจัดการหมวดหมู่จากเมนู หมวดหมู่ที่ยังมีรายการจะลบไม่ได้
- ยอดและงบประมาณคิดเฉพาะเดือนที่เลือก เงินคงเหลือคือรายรับลบรายจ่าย ไม่ใช่ยอดสะสมจากเดือนก่อน
- รายการและ CSV ในตารางใช้ตัวกรองปัจจุบัน ส่วนเมนูนำเข้า/ส่งออกสามารถส่งออก CSV ทุกรายการ
- JSON สำรองรายการ หมวดหมู่ และงบทุกเดือน พร้อมเวอร์ชันไฟล์ กู้คืนได้ทั้งเพิ่มรวมและแทนที่ ต้องยืนยันก่อนแทนที่
- เพิ่มรวมจะข้ามรายการ id และเนื้อหาตรงกัน ถ้า id ชนแต่รายละเอียดต่างกันจะเก็บทั้งสองรายการ งบเดือนเดิมมีลำดับความสำคัญเหนือไฟล์นำเข้า

## ข้อจำกัด

ข้อมูลอยู่เฉพาะเบราว์เซอร์/โปรไฟล์/อุปกรณ์และ origin ที่ใช้งาน ไม่มีสมาชิก ไม่มีซิงก์ข้ามอุปกรณ์ และไม่เข้ารหัส ควรเก็บ JSON สำรองในที่ปลอดภัย การล้างข้อมูลเว็บไซต์หรือโหมดไม่ระบุตัวตนอาจทำให้ข้อมูลหาย ไม่รองรับการแก้ไขพร้อมกันหลายแท็บ (อาจเขียนทับกัน) ควรใช้งานทีละแท็บ ไฟล์นำเข้าสูงสุด 10 MB / 100,000 รายการ / 1,000 หมวดหมู่ จำนวนเงินต่อรายการและงบสูงสุด 1 พันล้านบาท กราฟแท่งเปรียบเทียบ 6 เดือน แสดงยอดผ่าน tooltip หรือข้อความสำหรับโปรแกรมอ่านหน้าจอ Google Fonts ต้องมีอินเทอร์เน็ต มิฉะนั้นใช้ฟอนต์สำรองของเครื่อง

## การทดสอบ

Vitest + fake-indexeddb ตรวจการเพิ่ม แก้ไข ลบ อ่านข้อมูลใหม่ กู้คืน JSON ทั้งโหมดเพิ่มรวมและแทนที่ การคำนวณสตางค์ ยอดรวม วันที่ผิด การตรวจไฟล์ และ CSV
